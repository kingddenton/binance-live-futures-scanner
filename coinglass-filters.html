Calculation notes

RSI uses Wilder's RSI, period 14, calculated from completed candles. Price change compares the close of the latest completed candle with the preceding completed candle of the same duration.

Volume-change values include the still-forming current hourly candle, so the current window is an incomplete accumulation, not a forecast. RSI and price change use completed candles. The 24h RSI and price-change options follow Binance daily candle boundaries rather than rolling 24-hour calculations.

Funding, open interest and liquidation filters are not implemented in this version.

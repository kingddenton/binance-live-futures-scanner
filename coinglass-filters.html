Scan settings

RSI filters — select the timeframes to apply

All selected filters use AND logic. RSI values use the latest available candle, including its current forming candle. The 24h RSI uses Binance's 1-day candle.

MACD filters — select components and timeframes

Standard MACD settings: 12, 26, 9. DIF = EMA 12 − EMA 26; DEA = 9-period EMA of DIF; MACD histogram = DIF − DEA. Values use the latest available candle, including the current forming candle. Every selected component/timeframe filter uses AND logic. Negative and positive values are supported.

Price-change filters — select the timeframes to apply

Intraday changes compare the current forming candle price with the previous candle's close. The 24h change uses Binance's 24h ticker.

Supertrend filters — select timeframes and direction

Supertrend uses ATR(10) with a multiplier of 3. Choose Bullish or Bearish for each timeframe. The latest available candle, including its current forming candle, is used. All selected Supertrend conditions combine with your other filters using AND logic.

1m RSI Movement Tracker (40 → 70+)

Display-only tracker using RSI(14), regardless of the RSI period selected above. A pair is armed when 1m RSI reaches 40 or below.
